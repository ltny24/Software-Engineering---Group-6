# Directory and File Structure

* **docs/**: Project documentation.
  * **analysis-and-design/**
  * **management/**: Project management and progress tracking documents.
    * `Team Contract/`: Team contract and working guidelines.
    * `Weekly Report/`: Weekly progress reports (includes Sprint 1, Sprint 2, Sprint 3).
    * `AI_Usage_Log.md` / `AI_Usage_Log_2.md`: AI usage logs.
    * `Changes.md`: Changes made from PA2 to PA3.
    * `Project_Plan.md`: Initial project plan.
    * `Revised_Project_Plan.md`: Revised and updated Project Plan after feedback.
  * **requirements/**: System requirement specification documents.
    * `Prototype_Req/`: Contains images of UseCase_Specification.md.
    * `spec_specification/`: Detailed specification documents.
    * `Detailed_Vision_Document.md`: Revised and updated Vision Document after feedback.
    * `Project_Proposal.md`: Project proposal.
    * `UseCase_Specification.md`: Detailed Use Case specifications.
    * `Use_Case_Model.md`: Use Case models.
    * `Vision_Document.md`: Overview vision document.
  * **survey/**: User survey data and forms.
  * **test/**: Test plans, scripts, and reports.
* **src/**: Project source code.
  * **SpecKit/**: Files and configurations related to SpecKit.
    * `.specify/memory/`: SpecKit's temporary memory data.
    * `Brief_Summary/`: The team's brief summary of SpecKit.
    * `specs/001-university-portal/`: Files generated by SpecKit (`data-model.md`, `plan.md`, `quickstart.md`, `research.md`, `spec.md`, `tasks.md`).
      * `checklists/`: Checklists generated by SpecKit.
      * `contracts/`: Contracts and constraints generated by SpecKit.
  * **backend/**: Backend source code.
  * **frontend/**: Frontend source code.
  * **tests/**: Automated testing source code.
  * `README_WEB.md`: General guide and introduction to the web platform.
